# ACAR GIDA TOPTAN

Flutter Android uygulamasi icin ilk kaynak kod iskeleti.

## Bu pakette neler var?
- Tek uygulama icinde musteri / plasiyer / yonetici rol giris secimi (arayuz iskeleti)
- ACAR GIDA markali sade ana ekran
- Altı ürün kategorisi
- Sepet arayuzu icin ilk iskelet
- Gelistirme notlari ve backend tasarim dokumani

## Calistirma
1. Flutter SDK ve Android Studio kurun.
2. Arsivi cikartin.
3. Proje klasorunde terminal acin.
4. `flutter pub get`
5. `flutter run`

APK almak icin: `flutter build apk --release`

## Onemli
Bu ilk kaynak kod iskeletidir; henuz canli uygulama degildir.
Firebase kimlik dogrulama, veritabani, fotograf depolama, rol yetkileri,
plasiyer atama, siparis kaydi ve push bildirimleri henuz baglanmamistir.
Canliya cikmadan once backend guvenlik kurallari ve gercek cihaz testleri
tamamlanmalidir.
